Running it: this is a full-stack app. The repo here contains the React client/src and Node/tRPC server source; install dependencies with pnpm install (or npm install), push the Drizzle schema to PostgreSQL, then run the dev/build scripts. Static hosting alone cannot run the server, database, or PayPal webhooks — deploy to a Node host (Railway, Render, Fly.io) plus a PostgreSQL database.
