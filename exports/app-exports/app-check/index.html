Deployment requirements

⚠️ Full-stack application — cannot run on GitHub Pages

GitHub Pages / Vercel static hosting cannot run the Node.js backend, tRPC procedures, database queries, PayPal webhooks, or S3 uploads. Deploy the full stack to Railway, Render, Manus, or Fly.io.

  • Railway — Node.js backend + database, free tier available (recommended)
  • Render — backend + database, free tier available
  • Manus — production-ready full stack

Quick start

git clone https://github.com/damoneward38/Check.git
cd Check
pnpm install
pnpm db:push      # drizzle-kit generate && drizzle-kit migrate
pnpm dev          # NODE_ENV=development tsx watch server/_core/index.ts
pnpm build        # vite build + esbuild server bundle
pnpm test         # vitest run
