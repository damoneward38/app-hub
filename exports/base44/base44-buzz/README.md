# Buzz — AI Browser Sidekick

A Base44 browser extension built with WXT (Chrome MV3).

- Build: `cd BASE44-APPS/apps-examples/buzz && npm run build` → `.output/chrome-mv3` (verified passing)
- Load in Chrome: `chrome://extensions` → Developer mode → Load unpacked → select `.output/chrome-mv3`
- This page is a static showcase; the extension itself runs inside the browser.
