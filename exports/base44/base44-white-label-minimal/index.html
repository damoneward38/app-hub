Next.js · Base44 White-Label

A white-label app platform, minimal.

Tiny is a minimal white-label Base44 experience: Google sign-in, an apps grid, and a chat-based editor backed by a shared ownership table.

Google Login

Auth.js / NextAuth with a shared database and workspace.

Apps Grid

Create, browse and edit the apps a user owns.

Chat Editor

Conversational app creation using Base44 service integration.

Run it

1
cd BASE44-APPS/base44-platform-starter
2
cp examples/white-label-minimal/.env.example examples/white-label-minimal/.env.local
3
Fill DATABASE_URL, NEXTAUTH_*, Google OAuth and Base44 variables.
4
npm run minimal:dev → http://127.0.0.1:3001
This app is server-rendered and requires a migrated Postgres database plus OAuth credentials, so it is not served as a static preview. The landing page documents the verified build; source and build output are preserved locally.
